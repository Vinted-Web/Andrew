GARDERIE PWA - FICHIERS A DEPOSER SUR GITHUB

Déposez tous les fichiers de ce dossier à la racine du dépôt GitHub.
Le fichier d'accueil doit rester nommé index.html.

GitHub : Settings > Pages > Deploy from a branch > main > /(root) > Save.

Après publication, ouvrez l'adresse GitHub Pages :
- iPhone/iPad : Safari > Partager > Sur l’écran d’accueil.
- Android : Chrome > menu > Installer l’application.
- PC : Chrome ou Edge > icône d’installation dans la barre d’adresse.

Important : Supabase reste nécessaire pour consulter et synchroniser les données.
